# Dijkstra Maze Solver

シードベースの迷路を生成し、ダイクストラアルゴリズムで最短経路を求解する過程を可視化するデモプログラムです。

## 実行方法

```bash
cd case_deeps
python main.py
```

起動後：
1. 迷路が表示され、画面中央に **[Press Space]** が表示されます
2. **Space キー**を押すとダイクストラアルゴリズムが開始されます
3. アルゴリズム実行中、床の色が白→赤→青と変化し、探索過程を視覚化します
4. ゴール到達後、GIFアニメーションが保存され、画面に進捗が表示されます
5. ウィンドウを閉じると終了します

## インストール方法

### 必要なモジュール

```bash
cd case_deeps
pip install -r requirements.txt
```

### 依存モジュール一覧

- **pygame** (>=2.5.0): GUI描画とキー入力処理
- **imageio** (>=2.30.0): GIFアニメーション出力
- **Pillow** (>=10.0.0): 画像処理（imageioの内部利用）

## ファイル構成

| ファイル | 説明 |
|----------|------|
| `main.py` | エントリポイント。迷路生成→Space待機→ダイクストラ→GIF保存を統括 |

| `recorder.py` | フレームキャプチャとGIF保存（進捗バー付き） |
| `requirements.txt` | 依存モジュール一覧 |
| `README.md` | 本ファイル |

## アルゴリズム詳細

### 迷路生成
- **Recursive Backtracker** (Randomized DFS) を使用
- シード値を指定することで、同じ迷路を再現可能
- 100x100のグリッド、壁5px・通路1pxの比率で描画

### ダイクストラ法
- スタート: 左下 (0, 99)
- ゴール: 右上 (99, 0)
- 各セルの色変化:
  - **白**: 未訪問
  - **赤**: 訪問済み（キューに投入された状態）
  - **青**: 採用済み（最短距離確定、または最終経路）

### 画面仕様
- ウィンドウサイズ: 320x320px
- 右上に Step カウンタ表示
- 保存中は進捗バー (Saving GIF... X%) を表示
- 出力GIFサイズ: 320x320px以下
