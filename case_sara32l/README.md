# Dijkstra Maze Demo

A Python demo that generates a random maze, visualises the shortest path using Dijkstra's algorithm, records the animation as a GIF, and displays the step count.

## Features

- Random perfect maze generation (Prim's algorithm).
- Real‑time visualisation of Dijkstra's exploration (visited cells turn red).
- Final shortest path highlighted in blue.
- Step counter displayed in the top‑right corner.
- Press **Space** to start the algorithm.
- Animation saved as `maze_solution.gif` in the same folder.

## Requirements

Install the required packages:

```bash
pip install -r requirements.txt
```

## Running

```bash
python main.py
```

A window of size 320×320 pixels appears. Click the window, press **Space** to begin. Close the window when finished.

## Files

- `main.py` – the demo program.
- `requirements.txt` – required Python packages.
- `README.md` – this documentation.
