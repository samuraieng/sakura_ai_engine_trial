# Dijkstra Maze Demo

## 概要
Python + Pygame で実装された、ダイクストラ法による最短経路探索の可視化デモです。
シード固定の穴掘り法で 100×100 マスの迷路を生成し、アルゴリズムの探索過程を色で可視化します。

## インストール方法

```bash
cd case_kimi
. venv/bin/activate
pip install -r requirements.txt
```

## 実行方法

```bash
cd case_kimi
. venv/bin/activate
python main.py
```

## 操作方法

1. 起動後、画面中央に **[Press space]** と表示されます。
2. **Space キー** を押すとダイクストラ探索が開始されます。
3. 探索終了後、自動で `maze_demo.gif` を保存します。保存中は画面に進捗が表示されます。
4. 保存完了後、ウィンドウを閉じるまで待機します。

## ファイル構成

| ファイル | 説明 |
|---|---|
| `main.py` | エントリーポイント。イベントループと全体の制御を担当します。 |
| `maze_generator.py` | シード固定の穴掘り法で 201×201 の迷路を生成します。 |
| `dijkstra.py` | ヒープ付きダイクストラ法。探索過程を数ステップごとに yield して可視化します。 |
| `renderer.py` | Pygame 描画、フレーム録画、GIF 保存（320×320 以下に自動リサイズ）を行います。 |
| `requirements.txt` | 必要な Python パッケージ一覧です。 |

## 色の定義

| 色 | 意味 |
|---|---|
| 白 | 未探索の通路 |
| 赤 | ダイクストラで訪問した通路（探索候補） |
| 青 | 最短経路として確定した通路 |
| 黒 | 壁 |
| 緑 | スタート地点 |
| 金 | ゴール地点 |

## 仕様

- 迷路サイズ: 100×100 マス（論理ピクセル 201×201）
- スタート: 左下固定
- ゴール: 右上固定
- 最短経路探索: ダイクストラ法（優先度付きキュー使用）
- 表示更新: 数ステップごとに動的に描画を更新
- 録画: `maze_demo.gif`（320×320 以下にリサイズ）として同フォルダに保存
- Step 数: スタートからゴール到達までに床の色を変更した回数を右上に表示
